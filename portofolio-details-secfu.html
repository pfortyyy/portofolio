Project Overview

Security For You is a web-based blog platform for the bug hunting and cybersecurity community, built as a group project for a university course. Users can publish posts, read articles from others, and interact through likes and comments.

The application was built with Python and Django as a team project, covering user authentication, content management, and community interaction features.

My Contributions

Login Authentication

Implemented user registration and login so that only authenticated users can publish posts and interact with content.

Blog Content

Built the pages that display blog articles, along with the like and comment features for reader interaction.

Post Management

Developed the post menu where users can create, edit, and delete their own posts.

Responsive Interface

Designed a responsive user interface and applied the MVC structure to keep the code organized.
