Project Overview

Quement is a UI/UX prototype of an online beauty service booking application designed to simplify appointment scheduling between customers and beauticians. The application allows users to browse available beauticians, select preferred schedules, book services, and communicate through an integrated chat feature.

The project focused on designing an intuitive user experience with a clean interface, efficient booking flow, and user-centered design principles. This prototype was recognized as one of the Top 3 Best Projects at the Informatics Program Exhibition.

My Contributions

User Flow & Wireframing

Designed user flows and wireframes to create a seamless booking experience from registration to appointment confirmation.

UI Design

Created modern and user-friendly interfaces using Figma with consistent typography, colors, and design components.

Booking Experience

Designed appointment scheduling, beautician availability, booking confirmation, and service selection screens.

Messaging Feature

Designed an in-app chat interface allowing customers and beauticians to communicate before appointments.
